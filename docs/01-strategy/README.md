## Key Concepts

- **Core Value Proposition**: Social accountability through behavioral psychology
- **Target Audience**: 28M frustrated wearable users seeking accountability
- **Differentiation**: Psychology-first approach vs. feature-first competitors
- **Product Scope**: This repo builds the MARKETING WEBSITE, not the full platform
