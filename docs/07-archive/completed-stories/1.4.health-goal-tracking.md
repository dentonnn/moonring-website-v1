## Story
**As a** Moon Ring platform user,
**I want** to create, track, and manage my health goals across different categories,
**so that** I can monitor my progress and achieve sustainable behavioral change through structured commitment.

## Acceptance Criteria
1. [ ] Users can create health goals in 4 categories: movement, sleep, stress, recovery
2. [ ] Goal creation wizard provides smart defaults based on user assessment
3. [ ] Goals include target values, units, and timeframes (30-day commitments)
4. [ ] Progress tracking supports both manual entry and automatic wearable integration
5. [ ] Visual progress displays with category-specific color coding
6. [ ] Goal modification allowed within first 48 hours of creation
7. [ ] Goal completion triggers celebration and achievement recognition
8. [ ] Failed goals offer recovery pathways and recommitment options
9. [ ] Goal history and analytics show long-term progress patterns
10. [ ] Real-time progress updates with milestone notifications
11. [ ] Goal templates based on common health objectives
12. [ ] Integration with behavioral assessment for personalized recommendations

## Dev Notes

### Health Goal System Architecture
**Source:** [implementation-guide-nextjs-supabase-stripe.md, moon-ring-project-prd.md]

The health goal system implements Moon Ring's core behavioral change methodology:
- **Category-Based Goals**: 4 health categories matching Moon Ring design system
- **Commitment Psychology**: 30-day commitments with clear success criteria
- **Progress Tracking**: Both manual entry and wearable integration support
- **Real-time Updates**: Live progress synchronization across devices

### Database Schema for Goals
**Source:** [implementation-guide-nextjs-supabase-stripe.md]

Health goals table structure:
- **Core Fields**: id, user_id, category, title, description
- **Target Fields**: target_value, target_unit for measurable goals
- **Status Management**: status enum (active, paused, completed, archived)
- **Timestamps**: created_at, updated_at for tracking lifecycle

Goal progress table structure:
- **Progress Fields**: goal_id, user_id, value, unit, recorded_at
- **Real-time Support**: Enabled for supabase_realtime publication
- **Performance**: Indexed on goal_id and recorded_at for fast queries

### Category Color System Integration
**Source:** [prd.md]

Moon Ring health category colors:
- **Movement/Steps**: `#F7941D` → `#FFF200` gradient
- **Stress Management**: `#FF5A5A` → `#660000` gradient
- **Sleep**: `#52ACFF` → `#725CFA` gradient
- **Recovery**: `#2CE6FF` → `#006699` gradient

### Behavioral Psychology Integration
**Source:** [moon-ring-project-prd.md]

Goal system implements evidence-based behavioral psychology:
- **Implementation Intentions**: If-then planning during goal creation
- **Commitment Contracts**: Visual commitment display with social accountability
- **Loss Aversion**: Clear consequences for goal abandonment
- **Social Proof**: Community success stories and benchmarks
- **Habit Stacking**: Integration with existing behaviors

### Real-time Progress Architecture
**Source:** [implementation-guide-nextjs-supabase-stripe.md]

Progress updates flow:
1. **Manual Entry**: Form submission → database update → real-time broadcast
2. **Wearable Sync**: Device data → validation → progress calculation → update
3. **Real-time UI**: Supabase subscription → React state update → UI refresh
4. **Notifications**: Milestone detection → push notification service

### Goal Modification Rules
**Source:** [moon-ring-project-prd.md]

Goal modification constraints:
- **48-Hour Window**: Full modification allowed within first 48 hours
- **Commitment Integrity**: Limited changes after initial commitment period
- **Recovery Pathways**: Structured failure recovery without starting over
- **Escalation Options**: Ability to increase goal difficulty mid-cycle

### Progress Calculation Logic
**Source:** [implementation-guide-nextjs-supabase-stripe.md]

Progress tracking implementation:
- **Daily Targets**: Break down 30-day goals into daily objectives
- **Cumulative Tracking**: Sum progress against total commitment
- **Streak Calculation**: Consecutive days meeting daily targets
- **Completion Percentage**: Real-time calculation of goal completion

### Wearable Integration Points
**Source:** [moon-ring-project-prd.md]

Goal tracking integrates with wearable data:
- **Movement Goals**: Steps, exercise minutes, active calories
- **Sleep Goals**: Sleep duration, bedtime, wake time, sleep quality
- **Stress Goals**: Heart rate variability, meditation sessions
- **Recovery Goals**: Rest days, recovery heart rate, activity intensity

### Testing Requirements
**Source:** [implementation-guide-nextjs-supabase-stripe.md]

Goal system testing priorities:
- **Unit Tests**: Goal creation, progress calculation, status transitions
- **Integration Tests**: Real-time updates, wearable data integration
- **E2E Tests**: Complete goal lifecycle from creation to completion
- **Performance Tests**: Real-time update latency and database query optimization
- **Psychology Tests**: Validate behavioral psychology implementation effectiveness
