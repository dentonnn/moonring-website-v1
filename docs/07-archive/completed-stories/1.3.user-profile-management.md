## Story
**As a** registered user,
**I want** to manage my profile information, preferences, and account settings,
**so that** I can personalize my Moon Ring experience and maintain accurate account data.

10. [ ] Users can export their profile data for GDPR compliance
11. [ ] Profile completion wizard guides new users through setup

## Dev Notes

### Profile Management Architecture
**Source:** [implementation-guide-nextjs-supabase-stripe.md]

The profile system extends Supabase auth.users with the public.profiles table:
- **Profile Extension**: Additional user data beyond authentication
- **Real-time Updates**: Supabase subscriptions for live profile changes
- **File Storage**: Supabase Storage for avatar and document uploads
- **Data Security**: RLS policies ensure users can only access their own data

### Database Schema Integration
**Source:** [implementation-guide-nextjs-supabase-stripe.md]

Profiles table structure includes:
- **Core Fields**: id (UUID), email, full_name, avatar_url
- **Subscription Fields**: subscription_status, stripe_customer_id, trial_ends_at
- **Timestamps**: created_at, updated_at for audit trails
- **Foreign Keys**: References auth.users with cascade deletion

### Supabase Storage Integration
**Source:** [implementation-guide-nextjs-supabase-stripe.md]

Avatar upload implementation:
- **Bucket Configuration**: Public bucket for profile avatars with size limits
- **Security Policies**: Users can only upload to their own folder
- **File Optimization**: Client-side resizing before upload
- **URL Generation**: Secure signed URLs for avatar access

### Real-time Profile Updates
**Source:** [implementation-guide-nextjs-supabase-stripe.md]

Profile changes propagate via:
- **Database Triggers**: Automatic updated_at timestamp updates
- **Real-time Subscriptions**: Supabase real-time for live UI updates
- **Optimistic Updates**: Immediate UI feedback before server confirmation
- **Error Rollback**: Revert optimistic updates on server errors

### Privacy and Compliance
**Source:** [implementation-guide-nextjs-supabase-stripe.md]

GDPR compliance features:
- **Data Export**: Complete profile data in portable format
- **Right to Erasure**: Account deletion with data cleanup
- **Consent Management**: Granular privacy controls
- **Audit Logging**: Complete trail of data changes
