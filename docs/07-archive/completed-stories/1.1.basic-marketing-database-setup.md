## Dev Notes

### Database Schema Structure

```sql
-- Leads table (marketing focus)
CREATE TABLE leads (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  email TEXT UNIQUE NOT NULL,
  name TEXT,
  source TEXT, -- 'organic', 'paid', 'social', 'referral'
  utm_source TEXT,
  utm_medium TEXT,
  utm_campaign TEXT,
  utm_term TEXT,
  utm_content TEXT,
  referrer_url TEXT,
  landing_page TEXT,
  lead_score INTEGER DEFAULT 0,
  conversion_stage TEXT DEFAULT 'visitor', -- 'visitor', 'lead', 'trial', 'customer'
  gdpr_consent BOOLEAN DEFAULT false,
  gdpr_consent_date TIMESTAMPTZ,
  gdpr_consent_ip INET,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Orders table (e-commerce focus)
CREATE TABLE orders (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  order_number TEXT UNIQUE NOT NULL,
  customer_email TEXT NOT NULL,
  stripe_payment_intent_id TEXT UNIQUE,
  stripe_customer_id TEXT,
  product_variant JSONB NOT NULL, -- {size: 'medium', color: 'black'}
  amount_cents INTEGER NOT NULL,
  currency TEXT DEFAULT 'USD',
  status TEXT DEFAULT 'pending', -- 'pending', 'paid', 'shipped', 'delivered', 'cancelled'
  shipping_address JSONB,
  tracking_number TEXT,
  fulfillment_provider TEXT,
  shipped_at TIMESTAMPTZ,
  delivered_at TIMESTAMPTZ,
  metadata JSONB,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Basic users for demo access
CREATE TABLE basic_users (
  id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  email TEXT UNIQUE NOT NULL,
  demo_access_granted_at TIMESTAMPTZ,
  demo_access_expires_at TIMESTAMPTZ,
  metadata JSONB,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Email subscriptions
CREATE TABLE email_subscriptions (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  email TEXT UNIQUE NOT NULL,
  subscription_type TEXT DEFAULT 'newsletter', -- 'newsletter', 'product_updates', 'promotions'
  status TEXT DEFAULT 'active', -- 'active', 'unsubscribed', 'bounced'
  unsubscribe_token TEXT UNIQUE DEFAULT encode(gen_random_bytes(32), 'hex'),
  unsubscribed_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Analytics events
CREATE TABLE conversion_events (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  session_id TEXT NOT NULL,
  visitor_id TEXT,
  event_type TEXT NOT NULL, -- 'page_view', 'email_signup', 'demo_start', 'purchase_start', 'purchase_complete'
  event_properties JSONB,
  page_url TEXT,
  referrer_url TEXT,
  user_agent TEXT,
  ip_address INET,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

### File Locations
- Database migrations: `supabase/migrations/`
- TypeScript types: `src/types/database.ts`
- Supabase client: `src/lib/supabase/client.ts`
- Server client: `src/lib/supabase/server.ts`

### Environment Variables Required
```bash
# .env.local
NEXT_PUBLIC_SUPABASE_URL=your_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key
```

### RLS Policies
- **Leads**: INSERT allowed for everyone, SELECT/UPDATE/DELETE admin only
- **Orders**: All operations admin only
- **Basic Users**: Users can read own data, admin can all
- **Email Subscriptions**: INSERT public, user can update own, admin all
- **Analytics**: INSERT public, SELECT admin only
