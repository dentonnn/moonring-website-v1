## When to Archive

Move documents here when:
- ✅ Work is complete and implementation is live
- ✅ Document is deprecated/superseded by newer version
- ✅ Historical reference only, not actively used

## When NOT to Archive

Keep in active documentation if:
- ❌ Still referenced regularly
- ❌ Contains current requirements or specifications
- ❌ Needed for ongoing work
