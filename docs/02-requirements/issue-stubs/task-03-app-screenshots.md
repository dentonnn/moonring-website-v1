# Task 3 — App Screenshots (Gap 4)

- Title: Real App Screenshot Integration + CMS Management
- Owners: Engineering (Web), Design, Content
- Estimate: 2–3 weeks
- Dependencies: CMS models for screenshots; asset optimization pipeline

## Summary
Capture, optimize, and integrate real app screenshots across Hero, Demo, Success Stories, and How It Works. Manage via CMS.

## Acceptance Criteria (Done When)
- Real screenshots integrated across core pages
- CMS fields for screenshots with alt text and device tags; ISR configured
- Hero LCP image ≤100KB; all other screenshots ≤60–80KB and lazy-loaded
