# Implementation Roadmap

**Scope**: Moon Ring Marketing Website — gap closure plan aligned to PRD goals.

**Phasing**: Sequenced to maximize impact and reduce dependencies. Durations assume 1 FTE engineer + part‑time content/PMM.

  - Dependencies: CMS hosting; roles/permissions
