# PDF Design Brief: "The Science of Social Accountability"

**Project:** Lead magnet for Moon Ring Week 4 email campaign
**Deliverable:** 26-page PDF guide optimized for mobile reading
**Timeline:** 2-4 hours design + export
**Tools:** Canva (recommended) or Figma

---

## Design Philosophy

**Goal:** Create a professional, research-backed guide that feels:
- ✅ Credible (academic, not fluffy)
- ✅ Accessible (easy to read on mobile)
- ✅ Branded (Moon Ring visual identity)
- ✅ Actionable (worksheets and templates feel usable)

**NOT:**
- ❌ Over-designed (avoid excessive graphics that distract from content)
- ❌ Generic (no stock photo aesthetics)
- ❌ Intimidating (academic ≠ dense walls of text)

---

## Page Specifications

### Format
- **Dimensions:** 8.5" × 11" (US Letter, portrait)
- **Total Pages:** 26
- **Safe Margins:** 0.75" all sides (avoid text in bleed zones)
- **Bleed:** 0.125" (if printing, otherwise not required)

### File Export
- **Format:** PDF
- **Color Space:** RGB (digital-only, no print version)
- **Resolution:** 150 DPI (optimized for web, not print)
- **File Size Target:** <2 MB (for fast mobile download)
- **Compression:** Medium quality (balance between file size and readability)

## Brand Identity

### Color Palette

**Primary Brand Colors:**
```
Moon Ring Gradient:
  - Start: #FF33BA (Hot Pink)
  - End: #FF9966 (Coral Orange)

Gradient Direction: 135deg (diagonal, top-left to bottom-right)
```

**Supporting Colors:**
```
Dark Mode Base (for contrast):
  - Background: #0F0F14 (near-black)
  - Secondary BG: #1A1A24 (dark purple-gray)

Text Colors:
  - Primary Text: #FFFFFF (white)
  - Secondary Text: #E5E7EB (light gray)
  - Tertiary Text: #9CA3AF (muted gray, for footnotes)

Accent Colors:
  - Success Green: #4ADE80 (for checkmarks, positive examples)
  - Warning Red: #FF6B6B (for X marks, negative examples)
```

**Color Usage Rules:**
- **Gradient:** Use for title page, section dividers, accent bars
- **Dark backgrounds:** Pages 1-26 use dark mode aesthetic (matches Moon Ring brand)
- **Text:** Always white or light gray on dark backgrounds (WCAG AAA contrast)

### Typography

**Font Stack:**
```
Primary Font: Inter (or SF Pro if unavailable)
  - Modern, highly legible sans-serif
  - Excellent for digital reading
  - Available on Google Fonts (free)

Fallback: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif
```

**Type Scale:**

| Element | Size | Weight | Line Height | Color | Usage |
|---------|------|--------|-------------|-------|-------|
| Page Title (H1) | 32pt | 700 (Bold) | 1.2 | #FFFFFF | "CHAPTER 1", section titles |
| Subtitle (H2) | 24pt | 600 (SemiBold) | 1.3 | #FFFFFF | Chapter subtitles |
| Section Heading (H3) | 20pt | 600 (SemiBold) | 1.3 | #FF9966 (gradient accent) | Subsections |
| Body Text | 16pt | 400 (Regular) | 1.6 | #E5E7EB | Main content |
| Small Text | 14pt | 400 (Regular) | 1.5 | #9CA3AF | Captions, metadata |
| Footnotes | 11pt | 400 (Regular) | 1.4 | #9CA3AF | Citations |

**Typography Rules:**
- **Paragraph Spacing:** 16pt between paragraphs (generous white space)
- **Max Line Length:** 70-80 characters (improves readability)
- **Text Alignment:** Left-aligned (easier to read than justified)
- **Emphasis:** Use **bold** for key terms, *italic* for citations

## Accessibility Guidelines

### Color Contrast (WCAG AAA)
- **White text on #0F0F14:** 19.1:1 (excellent)
- **Light gray (#E5E7EB) on #0F0F14:** 14.5:1 (excellent)
- **Gradient text on #0F0F14:** Ensure minimum 7:1 contrast (test with lighter gradient end)

### Mobile Readability
- **Font size:** Never below 14pt (16pt for body ensures readability on small screens)
- **Line length:** Max 80 characters per line (prevents eye strain)
- **Touch targets:** Any interactive elements (if PDF has links) should be 44×44pt minimum

### Screen Reader Compatibility
- **Headings:** Use proper heading hierarchy (H1 → H2 → H3)
- **Alt text:** If any images/icons are used, include alt text descriptions
- **Reading order:** Ensure logical reading flow (top to bottom, left to right)
