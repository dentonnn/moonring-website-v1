## 📊 Personalization Variables

### Core Variables (All Emails)
- `{{NAME}}` - First name or "there"
- `{{POSITION}}` - Current waitlist position
- `{{REFERRAL_COUNT}}` - Number of referrals made
- `{{REFERRAL_LINK}}` - Unique referral URL
- `{{FOUNDER_NAME}}` - Founder's name
- `{{UNSUBSCRIBE_LINK}}` - Unsubscribe URL
- `{{PREFERENCES_LINK}}` - Email preferences URL

### Goal-Specific Variables (Week 2+)
- `{{PRIMARY_HEALTH_GOAL}}` - movement | sleep | stress | recovery
- `{{BLOG_LINK_ACCOUNTABILITY}}` - Goal-specific blog post URL
- `{{SUCCESS_STORY_NAME}}` - Persona name matching goal
- `{{SUCCESS_STORY_BEFORE}}` - Before stat
- `{{SUCCESS_STORY_AFTER}}` - After stat

### Progress Variables
- `{{POSITION_CHANGE}}` - Positions moved since last email
- `{{TOTAL_COUNT}}` - Total waitlist size
- `{{BADGE}}` - Current badge level (Bronze/Silver/Gold)
- `{{TIER}}` - Current tier (tier1/tier2/tier3)

### Urgency Variables (Week 7+)
- `{{FOUNDING_SPOTS_REMAINING}}` - Remaining Founding Member spots
- `{{FOUNDING_CLAIMED_COUNT}}` - Number of Founding Members claimed
- `{{DAYS_UNTIL_LAUNCH}}` - Days until launch

## 🧪 A/B Testing Strategy

### Email Subject Lines
Each week includes 3 subject line variants:
- **Variant A:** Curiosity-driven
- **Variant B:** Social proof
- **Variant C:** Direct/personal

**Testing Methodology:**
- 50/25/25 split for Week 1
- Winner gets 70% traffic, losers get 15% each for Week 2+
- Re-test every 2 weeks

### Content Variants
- Goal selection: Button grid vs. Dropdown (Week 1)
- Success story format: Narrative vs. Data-driven (Week 2)
- Referral incentive: Position jump vs. Feature unlock vs. Discount (Week 3)
- Survey length: 2 min vs. 5 min (Week 5)
- Founding Member pricing: Fixed 50% vs. Pay-what-you-want (Week 7)
