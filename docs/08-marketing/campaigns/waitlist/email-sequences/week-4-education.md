# Week 4: Educational Value Email

**Timing:** 21 days after signup (3 weeks)
**Segment:** All waitlist subscribers (Tier 1 + Tier 2)
**Primary Goal:** 25-30% PDF download rate
**Secondary Goal:** Position Moon Ring as thought leader in accountability science
**Behavioral Tactic:** Reciprocity principle (give valuable resource → increases likelihood of future conversion)

---

## Campaign Context

This email delivers the promised lead magnet while deepening engagement with educational content. By Day 21, subscribers have:
- Received welcome email (Day 0)
- Been exposed to identity-based messaging (Day 7)
- Seen social proof (Day 14)

Now they're ready for substantive value that positions Moon Ring as an authority in accountability science. The PDF download serves dual purposes:
1. **Immediate value** - Actionable insights they can use today
2. **Engagement signal** - Download behavior indicates high intent for future conversion

**Key Psychology:** The Reciprocity Principle states that people feel obligated to return favors. By providing genuine educational value (not just marketing), we create a psychological debt that increases likelihood of:
- Opening future emails
- Engaging with product launch
- Converting to paid customer

**Conversion Path:** Week 4 bridges awareness → consideration by demonstrating expertise without selling. Subscribers who download the PDF are 3-4× more likely to convert at launch (industry benchmark).

// Week 4 Educational Value Email - Delivery Logic
// Timing: Day 21 (3 weeks after signup)

interface WaitlistSubscriber {
  id: string;
  email: string;
  first_name: string;
  goal: string;
  goal_category: 'fitness' | 'professional' | 'health' | 'learning' | 'other';
  signup_date: Date;
  email_opens_count: number; // Tracks opens from Week 1-3
  source: string; // Where they signed up (e.g., "Product Hunt", "organic")
  tier: 1 | 2;
}

async function sendWeek4Email(subscriber: WaitlistSubscriber) {
  // TIMING CHECK: Only send on Day 21 (±4 hour window)
  const daysSinceSignup = getDaysSince(subscriber.signup_date);
  if (daysSinceSignup < 21 || daysSinceSignup > 21.25) {
    console.log(`Skipping: subscriber not at Day 21 (currently Day ${daysSinceSignup})`);
    return;
  }

  // ENGAGEMENT CHECK: Has subscriber opened any previous emails?
  const engagementLevel = subscriber.email_opens_count >= 2 ? 'high' : 'low';

  // SUBJECT LINE SELECTION: Choose variant based on goal + engagement + source
  let subjectVariant: 'A' | 'B' | 'C' | 'D';
  let subjectLine: string;
  let previewText: string;

  if (engagementLevel === 'high') {
    // Variant C: Direct value for engaged subscribers
    subjectVariant = 'C';
    subjectLine = `[${subscriber.first_name}] Your free guide: The Science of Social Accountability`;
    previewText = "23-page research summary + 7 strategies you can use today →";
  } else if (subscriber.source === 'Product Hunt' || subscriber.source === 'Hacker News') {
    // Variant D: Founder authenticity for early adopters
    subjectVariant = 'D';
    subjectLine = "Why I spent 6 months reading 200+ psychology papers";
    previewText = "And what I learned about making goals actually stick... →";
  } else if (subscriber.goal_category === 'professional' || subscriber.goal_category === 'learning') {
    // Variant B: Research authority for analytical audience
    subjectVariant = 'B';
    subjectLine = "What 10,000+ accountability studies reveal about habit change";
    previewText = "New research explains why you need more than willpower →";
  } else {
    // Variant A (default): Curiosity-driven for fitness/health goals
    subjectVariant = 'A';
    subjectLine = "The science behind why 92% of fitness goals fail";
    previewText = "(And the one strategy that changes everything) →";
  }

  // DOWNLOAD LINK GENERATION: Unique tracking URL per subscriber
  const downloadLink = `https://moonring.co/download/guide/${subscriber.id}?ref=email-week4&utm_source=waitlist&utm_medium=email&utm_campaign=week4-education&variant=${subjectVariant}`;

  // UNSUBSCRIBE LINK: Secure token-based unsubscribe
  const unsubscribeToken = generateUnsubscribeToken(subscriber.id);
  const emailHash = hashEmail(subscriber.email);
  const unsubscribeLink = `https://moonring.co/unsubscribe?token=${unsubscribeToken}&email=${emailHash}`;

  // GOAL FORMATTING: Convert to lowercase for natural language flow
  const userGoalLowercase = subscriber.goal.toLowerCase();

  // TEMPLATE SELECTION: Choose plain text vs HTML based on subscriber preference
  const emailFormat = await getSubscriberPreference(subscriber.id, 'email_format') || 'html';

  // VARIABLE SUBSTITUTION
  const variables = {
    FIRST_NAME: subscriber.first_name,
    USER_GOAL_LOWERCASE: userGoalLowercase,
    SUBJECT_LINE: subjectLine,
    PREVIEW_TEXT: previewText,
    DOWNLOAD_LINK: downloadLink,
    UNSUBSCRIBE_LINK: unsubscribeLink,
  };

  let emailBody: string;
  if (emailFormat === 'html') {
    emailBody = replaceVariables(HTML_TEMPLATE, variables);
  } else {
    emailBody = replaceVariables(PLAIN_TEXT_TEMPLATE, variables);
  }

  // SEND EMAIL via Brevo
  const emailPayload = {
    to: [{ email: subscriber.email, name: subscriber.first_name }],
    sender: { email: 'denton@moonring.co', name: 'Denton' },
    subject: subjectLine,
    htmlContent: emailFormat === 'html' ? emailBody : undefined,
    textContent: emailFormat === 'plain' ? emailBody : undefined,
    tags: ['waitlist', 'week4', 'education', `variant-${subjectVariant}`],
    params: variables, // For Brevo template system
  };

  await brevoClient.sendTransacEmail(emailPayload);

  // LOG METADATA for tracking
  await logEmailSent({
    subscriber_id: subscriber.id,
    email_type: 'week4_education',
    subject_variant: subjectVariant,
    sent_at: new Date(),
    download_link: downloadLink,
  });

  console.log(`✓ Week 4 email sent to ${subscriber.email} (Variant ${subjectVariant})`);
}

// BATCH SEND LOGIC: Process all Day-21 subscribers
async function sendWeek4BatchEmails() {
  const today = new Date();
  const day21Date = subDays(today, 21); // 21 days ago

  // Query subscribers who signed up exactly 21 days ago
  const eligibleSubscribers = await supabase
    .from('waitlist_subscribers')
    .select('*')
    .gte('signup_date', startOfDay(day21Date))
    .lte('signup_date', endOfDay(day21Date))
    .eq('unsubscribed', false)
    .is('bounced', null);

  console.log(`Found ${eligibleSubscribers.length} subscribers for Week 4 email`);

  // Send emails with rate limiting (Brevo: 600 emails/minute)
  for (const subscriber of eligibleSubscribers) {
    await sendWeek4Email(subscriber);
    await sleep(100); // 100ms delay = 600/minute max
  }

  console.log('✓ Week 4 batch send complete');
}

// HELPER: Generate secure unsubscribe token
function generateUnsubscribeToken(subscriberId: string): string {
  const secret = process.env.UNSUBSCRIBE_SECRET;
  const payload = { sub: subscriberId, exp: Date.now() + (365 * 24 * 60 * 60 * 1000) }; // 1 year expiry
  return jwt.sign(payload, secret);
}

// HELPER: Hash email for unsubscribe verification
function hashEmail(email: string): string {
  return crypto.createHash('sha256').update(email).digest('hex').substring(0, 16);
}

// HELPER: Replace template variables
function replaceVariables(template: string, variables: Record<string, string>): string {
  let result = template;
  for (const [key, value] of Object.entries(variables)) {
    const regex = new RegExp(`{{${key}}}`, 'g');
    result = result.replace(regex, value);
  }
  return result;
}

## Conversion Optimization Notes

### The Reciprocity Sequence (Behavioral Economics)

**Week 4's Role in the Funnel:**
1. **Week 1 (Welcome):** Established relationship, set expectations
2. **Week 2 (Identity):** Aligned product with subscriber's self-concept
3. **Week 3 (Social Proof):** Reduced perceived risk via testimonials
4. **Week 4 (Education):** ← **YOU ARE HERE** ← Create psychological debt via value delivery
5. **Week 5 (Involvement):** Activate commitment via small asks
6. **Week 7 (Founding Member):** Capitalize on reciprocity for conversion

**Why Week 4 is Critical:**
- **Reciprocity Principle** (Cialdini, 1984): People feel obligated to return favors
- By giving a high-value resource (23-page research guide) for free, we create a psychological imbalance
- Subscribers are 3-4× more likely to convert when they feel they've "received" before being asked to "give"

**Avoiding the Reciprocity Backfire:**
- ❌ **Wrong:** Low-quality PDF that feels like a bait-and-switch → Destroys trust
- ✓ **Right:** Genuinely valuable guide that delivers on promises → Builds reciprocity debt

**Quality Threshold:** The PDF must be *so good* that subscribers think "I can't believe this is free." If it feels like a lead magnet disguised as education, the reciprocity effect reverses (creates resentment).

### The "No Pressure" Approach

**Psychology:**
- **Reverse Psychology:** By removing pressure, we paradoxically increase interest
- **Authenticity Signal:** Most companies wouldn't say "You don't need our product" → Builds trust
- **Non-Needy Frame:** Positioning as educator (not salesperson) makes subscribers more receptive to future offers

**Risk Mitigation:** Some subscribers may take this literally and disengage. **Acceptable trade-off:** We'd rather have a smaller list of high-intent subscribers than a large list of disengaged people.

## Appendix: Behavioral Science References

This email leverages the following principles from behavioral economics and psychology:

1. **Reciprocity Principle** (Cialdini, 1984): Giving valuable resource creates obligation to reciprocate in future
2. **Implementation Intentions** (Gollwitzer & Sheeran, 2006): Specific "if-then" plans increase goal completion by 2-3×
3. **Goldilocks Effect** (Schwartz, 2004): Too much choice/accountability leads to paralysis; optimal level maximizes action
4. **Fresh Start Effect** (Dai et al., 2014): Temporal landmarks (New Year, birthday, Monday) increase motivation for change
5. **Public Commitment Effect** (Kiesler, 1971): Publicly stated goals increase follow-through (but can backfire if too early)
6. **Authority Principle** (Milgram, 1974): Research citations and expert positioning increase message credibility
7. **Social Proof** (Festinger, 1954): Testimonials from similar others reduce perceived risk of trying new approach

**Why This Matters:** By grounding the email in established behavioral science, we:
- Increase subscriber trust (credibility)
- Demonstrate thought leadership (authority)
- Position Moon Ring as science-backed (differentiation)
- Provide actionable strategies (value)
