## Visual Element Specifications

### 1. Stats Boxes (Large Numbers)

**Purpose**: Highlight research findings, key metrics, shocking statistics

**Color Themes by Context**:
- **Warning/Problem**: `from-red-50 to-orange-50 border-red-300` with `text-red-600`
- **Research**: `from-blue-50 to-purple-50 border-blue-300` with `text-blue-600`
- **Success/Growth**: `from-green-50 to-blue-50 border-green-300` with `text-green-600`
- **Insight**: `from-purple-50 to-pink-50 border-purple-300` with `text-purple-600`

**Template**:
```html
<div class="stats-box bg-gradient-to-br from-[color]-50 to-[color]-50 border-2 border-[color]-300 rounded-2xl p-8 my-8 text-center">
<p class="text-sm font-semibold text-[color]-900 uppercase tracking-wide mb-2">[Icon] [Label]</p>
<p class="text-6xl font-bold text-[color]-600 mb-2">[NUMBER]</p>
<p class="text-lg text-gray-800 font-medium">[Description]</p>
</div>
```

**Icons to Use**:
- 📊 Research data
- ⚠️ Warnings/problems
- 📈 Growth/improvement
- 🧠 Psychological concepts
- 📚 Academic research

### 2. Callout Boxes (Key Insights/Takeaways)

**Purpose**: Highlight key insights, takeaways, paradoxes, or important concepts

**Types**:
- **Key Insight**: 💡 icon
- **Key Takeaway**: 🎯 icon
- **The Problem**: ⚠️ icon (yellow border)
- **The Paradox**: 💡 icon

**Template**:
```html
<div class="callout-box bg-gradient-to-r from-pink-50 to-orange-50 border-l-4 border-[#FF33BA] p-6 my-8 rounded-r-lg">
<p class="text-lg font-semibold text-gray-900 mb-2">[Icon] [Title]</p>
<p class="text-gray-800 mb-0">[1-2 sentences of key insight]</p>
</div>
```

**For warnings** (use yellow):

### 4. Pull Quotes

**Purpose**: Emphasize memorable insights, break up text, create social media shareable moments

**Template**:

**Best practices**:
- Keep to 1-2 sentences maximum
- Choose insights that are tweet-worthy
- Pull from existing content, don't add new information
- Place after key sections to emphasize the point

## Content Guidelines

### Opening Hook (First 3 Paragraphs)
- Start with a relatable scenario
- Build narrative tension
- End with the key insight or problem statement in a callout box

### Research & Stats
- Always cite sources (even if fictional for this MVP)
- Use large numbers (50%+) in standalone stats boxes
- Group related metrics in multi-stat boxes
- Follow stats with explanatory paragraphs

### Real-World Examples
- Use specific names and details
- Include timeline markers (Week 1-2, Month 1, etc.)
- Show clear before/after contrast
- End with quantified results

### Practical Strategies
- Number 3-5 strategies
- Include concrete examples for each
- Use bold for strategy names
- Include both "what to do" and "what not to do"

### Moon Ring Integration
- Always explain how Moon Ring addresses the psychology discussed
- Use "Layer 1, Layer 2, Layer 3" structure
- Connect features to behavioral science principles
- Include results/metrics

### Action Plans
- 4-5 specific, actionable steps
- Use bold for action item headers
- Include examples or templates
- End with encouragement

## Article Checklist

Before publishing, ensure your article includes:

- [ ] Opening narrative hook (3 paragraphs)
- [ ] At least 1 stats box with large number
- [ ] At least 2 callout boxes (insights/takeaways)
- [ ] At least 1 comparison table
- [ ] At least 2 pull quotes
- [ ] Real-world example with timeline
- [ ] Research citations (3-5 minimum)
- [ ] 3-5 practical strategies
- [ ] Common mistakes section with table
- [ ] Moon Ring integration (3 layers)
- [ ] Action plan (4-5 steps)
- [ ] CTA footer with link
- [ ] Section divider before action plan

## Recommended Article Length

- **Word count**: 1,800 - 2,500 words
- **Reading time**: 6-8 minutes
- **Sections**: 8-12 major sections
- **Visual elements**: 8-12 total (mix of stats, callouts, tables, quotes)
