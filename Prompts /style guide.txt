  Usage Instructions for Figma Make

  How to Apply This Style Guide:

  1. Copy the entire CSS into Figma Make's
  custom CSS section
  2. Reference variables in your prompts: "Use
   var(--brand-gradient) for primary buttons"
  3. Apply component classes: "Add class
  'glass-card' to testimonial containers"
  4. Use health category gradients: "Apply
  var(--sleep-gradient) to sleep category
  cards"

  Quick Reference for Prompts:

  Primary CTA: class="btn-primary"
  Secondary CTA: class="btn-secondary"
  Glass cards: class="glass-card"
  Form inputs: class="form-input"
  Health cards: class="health-card
  health-card-sleep"
  Animations: class="animate-fade-in" or
  "animate-slide-up"
  Container: class="container"

  This style guide provides Figma Make with a
  complete design system that maintains Moon
  Ring's behavioral psychology focus while
  being flexible enough for rapid prototyping!
